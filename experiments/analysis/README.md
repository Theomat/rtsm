# How to use?

## Steps

1) Run ``stats_tests.py``
2) run your desired script

## Scripts

- ``cmp_features.py`` to compare the features kept by solutions
- ``count_timeouts.py`` to compare timeouts
- ``produce_dist.py`` (Not used in the paper) to plot cumulative distribution of score
- ``produce_gains.py`` (Used for appendix) to get the tables of the full data
- ``produce_improvements_plot.py`` to get the plot on the impact on iterative solving
- ``produce_plots.py`` to plot scatter plot of Kendall with respect to cost reduction
- ``produce_violinplots.py`` to make the violin plots
